READYSETPREP SUPABASE ACCOUNT SETUP

What this adds
--------------
- Real parent/guardian email + password login
- Multiple student profiles under one parent account
- Selected-student context throughout Practice and Tests
- Cloud-backed assessment history
- Cloud-backed concept-practice progress
- Cloud-backed full-passage practice progress
- Cloud-backed in-progress test state
- Data separated by authenticated user and student using Supabase Row Level Security

1. Create a Supabase project
----------------------------
Create a project at Supabase.

2. Create the tables and security policies
------------------------------------------
Open Supabase > SQL Editor.
Paste and run SUPABASE_SETUP.sql from this package.

3. Configure authentication URLs
---------------------------------
In Supabase Auth URL configuration, set your Site URL to the production site.

For ReadySetPrep with the custom domain:
https://readysetprep.ai

Add this redirect URL:
https://readysetprep.ai/login.html

For preview deployments, add the preview URLs you actually use.

4. Get the browser project settings
-----------------------------------
In Supabase, copy:
- Project URL
- Publishable key

Do NOT use a service-role/secret key in the website.

5. Edit supabase-config.js
--------------------------
Replace:

YOUR_SUPABASE_URL
YOUR_SUPABASE_PUBLISHABLE_KEY

with the values from your Supabase project.

6. Upload/deploy these new files
--------------------------------
supabase-config.js
rsp-cloud.js
students.html
SUPABASE_SETUP.sql can stay out of the public deployment if preferred.

Also upload the updated:
index.html
login.html
practice.html
primary-tests.html
lower-tests.html
privacy.html

7. How assessment tracking now works
------------------------------------
The existing ReadySetPrep test/report UI still works, but student-specific state
is stored under the selected student's account and synchronized to Supabase.

Tracked cloud state includes:
- Primary 2 assessment history
- Lower Level assessment history
- concept practice progress
- Primary 2 full-passage progress
- saved Primary 2 test attempts
- saved Lower Level test attempts

The browser keeps a student-specific cache for fast loading. Supabase is the
cross-device source of truth.

8. Existing browser data
------------------------
When the first student is selected after this upgrade and there is no cloud or
student-specific state yet, the app attempts to migrate existing ReadySetPrep
assessment/practice data from that browser into that student.

9. GitHub / hosting
-------------------
The Supabase account and progress features work from a static frontend, including
GitHub Pages or Cloudflare Pages.

The existing ReadySetPrep _worker.js Contact email feature is Cloudflare-specific.
It is separate from Supabase login/progress tracking.
