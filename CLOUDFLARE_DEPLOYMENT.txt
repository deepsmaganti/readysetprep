READYSETPREP CLOUDFLARE DEPLOYMENT

This website package no longer contains _worker.js or a functions/ folder.

Cloudflare Pages should treat the ReadySetPrep repository as a static site.

The dynamic features are now handled by Supabase:
- account login
- student profiles
- assessment reports
- practice progress
- contact email

For the website:
1. Upload/push all files in this ZIP to the root of your GitHub repository.
2. Keep the Cloudflare Pages project connected to that GitHub repository.
3. No Cloudflare Pages Function or Worker is required.
4. Keep your existing custom domain readysetprep.ai.

Supabase:
- Run SUPABASE_SETUP.sql.
- Configure supabase-config.js.
- Deploy the separate Supabase Edge Function named contact-email using the
  provided contact function file/instructions.

Because _worker.js has been removed, a Cloudflare Worker should no longer be
part of the Pages deployment.
